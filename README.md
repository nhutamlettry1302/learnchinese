# Rừng Cá Voi Roxie – hướng dẫn nhanh

1. Supabase → SQL Editor → dán toàn bộ `supabase.sql` → Run. (Chạy lại được, không lỗi.)
2. Mở `doi-mat-khau.sql`, thay MAT-KHAU-CUA-ROXIE bằng mật khẩu giáo viên → Run.
3. Tạo lớp: Table Editor → bảng `classes` → thêm dòng (mã lớp + tên lớp).
4. Tải toàn bộ file và thư mục `img` lên GitHub (repo Private).
5. Cloudflare Pages → Connect to Git → chọn repo → Deploy (build command và output để trống).
6. `config.js` đã điền sẵn URL và khóa publishable.
